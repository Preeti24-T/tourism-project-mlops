# Wellness Tourism XGBoost MLOps Project

## Objective
Predict tourism package purchases using XGBoost.

## Dataset
4,128 customer records.

## Data Quality
- Preserve all original customer records
- Preserve CustomerID for traceability
- Standardize Gender, MaritalStatus, Occupation
- Validate missing values, duplicates, and target

## Model
XGBoost with GridSearchCV and stratified splitting.

## Evaluation
Accuracy, Precision, Recall, F1-score, ROC-AUC.

## Experiment Tracking
MLflow.

## CI/CD
GitHub Actions.

## Deployment
Streamlit Community Cloud.

## Limitations
The full-feature model includes customer interaction
variables. It is not a strictly pre-contact model.
